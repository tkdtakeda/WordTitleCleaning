    このツールの使い方

    できること

    Word ファイル（.docx / .docm / .dotx / .dotm と、旧形式の .doc / .dot）と PDF の 「タイトル」だけを、まとめて空にします。 Word では〈ファイル → 情報 → プロパティ → タイトル〉の欄、 PDF ではブラウザで開いたときにタブに出る名前がこれにあたります。 古いファイル名や見出しがタイトルに残ったまま配布するのを防げます。

    切り替えれば、ファイル名をタイトルにすることも、全ファイルに同じタイトルを設定することもできます。

    使い方

    1. 1

      ファイルをドロップする

      これだけで、タイトルを空にして保存まで進みます。 Word と PDF を混ぜても、フォルダーごとでもかまいません。

    2. 2

      中身を確かめたいときは「ファイルを選ぶ」

      こちらは一覧に追加するだけで、実行ボタンを押すまで何もしません。 各行の「根拠」（）で、いまのタイトルや、PDF がタブにどう表示されるかを確認できます。 Ctrl+V での貼り付けも同じ動きです。

    3. 3

      画面下のボタンを押す

      押せないときは、その理由がボタンの左に出ています。

    タイトルの処理の選び方

    • タイトルを空にする（既定）：手元で開くならこれで十分です。PDF のタブにはファイル名が出ます。
    • ファイル名をタイトルにする：保存するファイル名から拡張子を除いたものを入れます。 Web やイントラに置くと URL の末尾（例: download.aspx）がタブに出てしまう場合や、 アクセシビリティ規格（PDF/UA）でタイトルが必須の場合に向いています。 ただし、後でファイル名を変えてもタイトルは古いまま残ります。
    • 同じタイトルを設定する：全ファイルに同じ文字を入れます。

    PDF について

    • PDF のタイトルは 2 か所にあり、両方を処理します。 Edge / Chrome は文書情報辞書の /Title を、Firefox は XMP メタデータの dc:title を優先してタブに表示するためです。 Acrobat は「タイトルを表示する」設定（DisplayDocTitle）のときだけタイトルを出し、無ければファイル名を出します。
    • 空にするときは、タイトルの部分を同じ長さの空白で塗りつぶします。ファイルの大きさも構造も変わりません。 圧縮されていて塗りつぶせない場所だけは、PDF 標準の追記保存でタイトルを除いた新しい版を末尾に足し、古い圧縮データは無効にして中身を消します。
    • 書き込むときは、古いタイトルを同じ方法で消したうえで、新しい値を追記保存で足します。
    • 以前の編集で追記保存された過去の版に残るタイトルも、あわせて消します。
    • 保存する前に出力を読み直し、タイトルが期待どおりか、どこにも残っていないかを確かめます。確認で問題が見つかったときは保存しません。
    • PDF/UA（アクセシビリティ規格）への準拠を宣言している PDF は一覧に「PDF/UA」と出ます。タイトルが必須なので、空にすると要件を満たさなくなります。

    Word の「空にする」の中身

    • docProps/core.xml の <dc:title> を要素ごと取り除きます。タイトルの文字はファイルのどこにも残りません。
    • もともとタイトルが無いファイルは、1 バイトも変更せず元のファイルをそのまま出力します（PDF も同じ）。落としたファイルの数と保存されるファイルの数は必ず一致します。

    保存のされ方

    • 1 件なら、そのファイル 1 つがダウンロードされます。
    • 2 件以上なら、既定では ZIP 1 つにまとまります（ZIP の中では出力名がそのまま残ります）。
    • ダウンロードフォルダーに同じ名前のファイルがあると、ブラウザが自動で (1) を付けます。これはブラウザの動作でツールからは変えられません。

    変更されないもの

    書き換えるのはタイトルだけです。本文・書式・作成者・作成日時・更新日時・その他のプロパティには一切触れません。 .docx 系ではタイトル以外のパートを圧縮されたままのバイト列で複製し、.doc では SummaryInformation のタイトルの値だけを、 PDF ではタイトルの部分だけを書き換えます。 一覧の各行にある「根拠」（）から、実際に何を書き換えたかを確認できます。

    旧形式 .doc について

    • 「タイトルを空にする」は .doc でもそのまま使えます。 .docx に変換する必要はありません。
    • .doc ではタイトルが SummaryInformation という領域に入っています。その文字を 0 で塗りつぶすので、ファイルの大きさも中の構造も一切変わりません。
    • タイトルの書き込み（ファイル名・同じタイトル）は .doc では行えません。 文字数によって領域の大きさが変わり、ファイルを作り直す必要があってリスクが高いためです。Word で .docx として保存し直してください。該当するファイルは一覧で「この形式は対象外」と表示されます。

    できないこと

    • パスワードや暗号化で保護された Word / PDF は処理できません。
    • 電子署名付きの PDF は処理できません（1 バイトでも書き換えると署名が無効になるため）。
    • 相互参照が壊れている PDF は、位置を動かさずに消せる範囲でだけ「空にする」を行います。タイトルの書き込みはできません。
    • ZIP64 形式（極端に大きいファイル）、暗号化された ZIP は読み取れません。
    • タイトル以外のプロパティ（作成者・会社名など）は消えません。Word の〈ドキュメント検査〉などをお使いください。
    • 元のファイルを直接書き換えることはできません。必ず新しいファイルとして保存されます。

    動作環境

    Microsoft Edge / Google Chrome（バージョン 103 以降）で、この HTML をそのまま開いて使えます。 サーバーも追加のインストールも不要です。ファイルはこのパソコンの中だけで処理され、どこにも送信されません。 アイコンの表示にだけインターネット接続を使います。
